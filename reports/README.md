## AAV winter reruns (`aav_run_*`)

One command rebuilds the 2027 AAV board from the current pool, projections and likely-keeper list:

```
PYTHONDONTWRITEBYTECODE=1 python3 tools/aav_single_pass.py [--write] [--override] [--projections steamer|atc]
```

- No flags: print the run report only. `--write`: also save `reports/aav_run_YYYY-MM-DD.md` + `.csv` (a second run the same day gets `_HHMM`) and update the `AAV_2027` block in `data/aav-2027.js`, but only if a price changed.
- Every report has a pot/inflation line (solved pot H/P, the 2570 x 1.1689 reference pot, implied inflation), the $2,570 cash check, and a diff vs the previous `aav_run_*.csv`: players moved and by how much, added to or dropped from the 250. The first run (2026-11-14) diffs against the v3.1 baseline (`/workspace/db2027/excel_method/aav_2027_v3_1.csv`).
- The CSV has one row per pool player: `status` is keeper / paid / stash / none, `aav` is the board price (for keepers, the display-only keeper AAV), and `unrounded` is the curve value.
- Likely keepers: edit `KEEPERS_CSV` at the top of the script (today: `/workspace/db2027/keepers/keeper_split_2026-11-20_room.csv`, 48 / $512). It must match `SEED2026.picks` in `data/seed-2027.js`; `--write` refuses if they disagree.
- Cutoff: `CUTOFF_DATE` at the top of the script (the only place the date lives) is the AAV lock, set right after LABR 2027: `2027-03-15`, a placeholder until LABR publishes its date. After that date `--write` refuses unless `--override` is given.
- `--projections atc` needs `/workspace/db2027/atc/2027_bat.json` and `2027_pit.json` (FanGraphs JSON export). Until those exist, it stops with an error. It never falls back to Steamer.
- New Steamer pull: refresh `/workspace/db2027/steamer` (`match.py`, then `valuation.py`) first. If the stored pool values don't match the projection JSON, the run stops and says so.
- Check: `node tests/single_pass_test.mjs`. It compares the app against the committed reference board `tests/fixtures/ref_board_<date>.csv`; on every pool refresh, after sign-off and before merge, rebuild it with `node tools/build-ref-board.mjs` (verify: `node tools/build-ref-board.mjs --check`). See `tests/README.md`.
- CBS eligibility, every pool refresh (after the new seed is in `data/`): `PYTHONDONTWRITEBYTECODE=1 python3 /workspace/db2027/eligibility/emit_elig_2027.py`, then `node tools/apply-cbs-elig.mjs --write`. The first rebuilds `data/elig-2027.js` for the current Draft List from the CBS export (`/workspace/db2027/cbs/elig-pages/all-hitters.csv`); a hitter with no CBS row gets the league backup from the cached statsapi games (5 or more at a position this year, or DH when that is all he played). The second copies each hitter's non-empty `elig` into `SEED2026.players` (same tokens the seed already uses, including MI/CI) and leaves pitchers alone. An empty backup keeps the seed value and is listed. The app reads those seed positions everywhere (Projections, Draft List section, cards, dialog, slotting, filters, and the Draft List PDF). Do not edit `elig` by hand.
- Rotoworld links, every pool refresh (after the new seed is in `data/`): `PYTHONDONTWRITEBYTECODE=1 python3 tools/rotoworld-harvest.py --sitemap-years all --prev-seed <old data/seed-2027.js> --out reports/rotoid_harvest_<date>.csv --write-rotoid` (crawl-delay 10, roughly 25+ minutes with all sitemaps). It fills only players with no link, never replaces a stored id unless the player changed teams and the new club's page disagrees, and lists ambiguous / unmatched names in `reports/rotoid_harvest_<date>_unresolved.csv` (resolve those by hand; never auto-pick). Check `_spotcheck.csv` (10 links, HTTP 200 + name on page) and `node tools/test-rotoworld-links.mjs`; bump APP_VER for the new `data/rotoid.js`. 2026-11-20: Eno's prototype mapping merged with `--from-csv` (229 of 314; 616 / 701 linked; 85 in `rotoworld_unresolved_2026-11-20.csv`).
- After sign-off: rebuild the printed Draft List PDF from the live Draft List (`python3 /workspace/db2027/rosters/build_pdf_<date>.py`, copied from the latest one with the new date), verify with pdftotext (count = Draft List count, struck players absent), save to OneDrive `CoworkOS/Fantasy Baseball/CTHL 2027 Draft List.pdf` (archive the old copy to `Fantasy Baseball/Archive/` first), and update `landing/CTHL-2027-Draft-List.pdf` on `landing-preview` locally (push only with Steven's go).
